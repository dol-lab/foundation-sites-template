# A Space

A post and the sidebar, laid out as defaultspace prints a Space. A post is a `.card` with an avatar, a header, the content and a footer of chips and avatars. The sidebar holds tabs, the main menu and accordions of `<details>`. Their layout comes from this library, some details from defaultspace's own CSS.

The markup below the card is captured from Spaces and shown in place (`html-partials/_space-post.html`, `_space-sidebar.html`).
