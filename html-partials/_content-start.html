Getting started

The styles of Spaces: a themeable fork of Foundation for Sites 6. Every component on this page shows its markup below it. The source is on GitHub.

Two builds

  • css/app.css styles pages we own.
  • css/app-backend.css goes into pages we don't own (wp-admin, the KISDarchiv theme). It only styles markup inside .f.

Theming

The palette follows the device's light or dark mode. Attributes on any element change it for that element and everything inside:

  • data-theme="light" or "dark" forces a mode.
  • themed with --f-color-theme tints the surfaces toward a hue. Every Space does this with its own color.
  • --f-color-brand-base overrides the brand color, --f-radius every corner.

For agents

llms.txt is this page as markdown: every section with its intro and the markup of each example, then the reference docs. It is built with the page.

Build

bun install, then bun run build (CSS), bun run build:html (this page and llms.txt) or bun start (both, then watch and serve). Edit index.src.html and html-partials/, never index.html.
